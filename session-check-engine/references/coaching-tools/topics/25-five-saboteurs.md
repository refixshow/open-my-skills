# T25 Pięciu sabotażystów

## Use when

Użyj jako lekkiej typologii języka samoutrudniania, gdy powtarzalny wewnętrzny głos obniża pewność, odwleka działanie lub narzuca sztywny standard. Nazwa ma zwiększać dystans, nie etykietować osobę.

## Do not use when

Nie diagnozuj osobowości ani nie traktuj każdego krytycznego głosu jako wroga. Nie pomijaj pozytywnej intencji, realnego ryzyka lub potrzebnej ostrożności.

## Observable signals

- atak personalny i porównywanie z innymi;
- wyolbrzymianie trudności oraz odkładanie;
- katastroficzne przewidywanie porażki;
- moralizujące „powinieneś”, „nie wolno”, „wstyd”;
- rozkazujące „musisz”, perfekcjonizm i utrata elastyczności.

## Process

1. Zbierz kilka konkretnych sytuacji i dosłowne zdania wewnętrzne.
2. Dopasuj wzorzec roboczo: krytyk, podcinacz skrzydeł, pesymistyczny wróżbita, oceniający ksiądz lub rozkazujący generał.
3. Sprawdź, jak wzorzec działa i jaką pozytywną intencję próbuje realizować.
4. Oddziel intencję od kosztownej strategii.
5. Zbuduj adekwatniejszy sposób ochrony, motywowania lub realizacji zadania.
6. Sprawdź wzorzec w kolejnych sytuacjach zamiast uznawać etykietę za stałą.

## Example interventions

- „Jak dokładnie brzmi ten głos, bez streszczania go?”
- „Który wzorzec najlepiej opisuje sposób działania, a nie Ciebie jako osobę?”
- „Jaką dobrą funkcję próbuje spełnić i jak można ją zachować bez ataku?”

## Limits

Typologia jest mapą edukacyjną, nie zwalidowanym testem psychologicznym. Krytyczny głos czasem przekazuje ważne dane, które trzeba oddzielić od jego formy.
