# T17 Rozwijanie perspektyw

## Use when

Użyj, gdy jedna perspektywa dominuje decyzję i klient potrzebuje rozdzielić twórcze możliwości, krytyczne ryzyka oraz realistyczne warunki wykonania.

## Do not use when

Nie używaj zabawy skojarzeniowej zamiast potrzebnych danych. Nie narzucaj ruchu, odgrywania ról ani symboli bez zgody klienta.

## Observable signals

- marzyciel jest natychmiast tłumiony przez krytyka;
- ryzyka są pomijane albo traktowane jako dowód, że pomysł jest niemożliwy;
- klient nie oddziela generowania opcji od ich oceny;
- coach sam dostarcza wszystkie perspektywy.

## Process

1. Nazwij sytuację, w której potrzeba większej elastyczności.
2. Rozdziel fizycznie lub werbalnie role Marzyciela, Krytyka i Realisty.
3. Z każdej roli zbierz dane bez mieszania funkcji.
4. Porównaj: możliwości, ryzyka i warunki realizacji.
5. Jeśli potrzeba dalszej elastyczności, użyj bezpiecznych skojarzeń, osób lub pozycji jako generatorów perspektyw.
6. Zintegruj wnioski i wybierz testowalny następny krok.

## Example interventions

- „Najpierw dajmy Marzycielowi dwie minuty bez krytyki. Co byłoby możliwe?”
- „Teraz jako Krytyk wskaż trzy ryzyka, ale bez wydawania werdyktu.”
- „Co Realista potrzebuje wiedzieć lub sprawdzić w małym eksperymencie?”

## Limits

Skojarzenie jest bodźcem do myślenia, nie dowodem. Decyzje wysokiego ryzyka nadal wymagają faktów, konsultacji i realnej oceny konsekwencji.
