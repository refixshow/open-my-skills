# T09 Tabela potrzeb

## Use when

Użyj, gdy klient odczuwa ogólne niezadowolenie, kilka potrzeb konkuruje ze sobą albo dotychczasowy sposób zaspokajania ważnej potrzeby przestał działać.

## Do not use when

Nie traktuj sumy punktów jako obiektywnej miary szczęścia ani nie narzucaj zamkniętej listy potrzeb. Nie przechodź do planu przed sprawdzeniem znaczenia niskiej oceny.

## Observable signals

- klient mówi „czegoś mi brakuje”, ale nie potrafi tego nazwać;
- powtarzający się konflikt dotyczy autonomii, granic, przynależności lub innej potrzeby;
- klient zna potrzebę, ale realizuje ją w kosztowny lub nieskuteczny sposób;
- kilka niskich ocen wymaga priorytetyzacji.

## Process

1. Wspólnie wybierz adekwatne potrzeby.
2. Oceń aktualne zaspokojenie każdej w skali 0-10.
3. Dla niskich lub ważnych ocen opisz dotychczasowy sposób realizacji.
4. Sprawdź koszt, kontekst i skuteczność tego sposobu.
5. Zaprojektuj nową, konkretną formę realizacji.
6. Wybierz jedną potrzebę do eksperymentu i ustal przegląd.

## Example interventions

- „Która niezaspokojona potrzeba najlepiej tłumaczy napięcie w tej sytuacji?”
- „Jak dotąd próbowałeś dbać o autonomię i jaki był koszt tej strategii?”
- „Jaki mały sposób zadbania o granice możesz przetestować do następnej rozmowy?”

## Limits

Oceny są subiektywnym zdjęciem chwili. Niska liczba sama nie wskazuje przyczyny ani właściwej interwencji.
