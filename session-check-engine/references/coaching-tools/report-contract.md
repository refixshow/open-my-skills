# Session review contract

## Required opening

State:

- what transcript was reviewed;
- whether speakers and timestamps were reliable;
- that the review identifies supervision hypotheses rather than objective errors;
- any material context missing from the transcript.

## Required sections

### What worked

Name 2-4 moments where the coach's intervention, restraint, contracting, or follow-up was supported by the transcript. This prevents a one-sided hunt for faults.

### Highest-value opportunities

Return 3-7 entries, ordered by expected usefulness rather than chronology.

For every entry include:

1. **Session moment** - timestamp or line reference plus a minimal quote.
2. **Observation** - only what is directly present in the transcript.
3. **Interpretation** - the client need, pattern, or decision point that may be present.
4. **Plausible tool** - topic ID and tool name.
5. **Why it may fit** - connect the signal to the tool's indications.
6. **Possible intervention** - one concise question, reflection, or process invitation.
7. **Alternative reading** - why using no tool or a different response may have been better.
8. **Source basis** - PDF page and/or audio timestamp from the topic reference.
9. **Confidence** - `high`, `medium`, or `low`, followed by one sentence explaining the rating.

### Practice priorities

Name 1-3 coach behaviors to rehearse. Express each as an observable action, for example: "Before proposing a plan, reflect the client's decision criterion and ask for confirmation."

## Confidence calibration

- **High:** explicit client signal, clear tool indication, reliable speaker/timestamp, and aligned source guidance.
- **Medium:** plausible signal and source fit, but transcript context or speaker intent is incomplete.
- **Low:** indirect signal, ambiguous attribution, weak source match, or missing surrounding context.

Never convert several low-confidence clues into a high-confidence conclusion.

## Language

Write in the user's language. Use direct, non-clinical wording. Prefer "possible opportunity" over "mistake" and "the transcript suggests" over claims about the client's inner state.
