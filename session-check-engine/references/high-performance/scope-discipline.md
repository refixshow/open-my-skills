# Session scope discipline

## Primary rule

Judge the session against its declared topic. The current session may draw on earlier client context, but it does not become a review or lecture on every High Performance pillar.

## Three kinds of cross-topic reference

1. **Useful bridge** - brief, client-led, necessary to make the current topic concrete, and followed by a return to the primary thread. Credit it.
2. **Unclear detour** - related material appears, but its function or return path is not visible. Ask what purpose it served or mark medium confidence.
3. **Scope drift** - the coach teaches or processes another module at length, the client becomes an audience, and a primary-session checkpoint loses time. Flag it as a first-sieve issue.

Example: during clarity, a short question about whom the client wants to serve may clarify identity. A generic lecture on techniques of influence belongs to S08 and is drift if it replaces identity, values, or clarity work.

## Function over script

- Do not compare the transcript line by line with the source questionnaire.
- Map each coach move to its function: assess, clarify, evoke, challenge, teach briefly, apply, integrate, or contract.
- Treat a source question as covered when the client reached the intended reflection through another formulation.
- Treat a question as functionally missing when its purpose remained unresolved and the omission weakened the session outcome.

## Teaching test

A teaching segment is more likely useful when it is concise, permission-based, tailored to the client's words, followed by reflection, and connected to an application. It is more likely a lecture when it is long, generic, unrelated to an expressed need, or followed by no client meaning-making.

## Partial transcripts

Never infer that opening, close, exercise, or homework was missing when the supplied transcript is visibly partial. Report only the absence from the reviewed material.
